# Sudoku Multiplayer (C, TCP, GTK3)

Jeu de Sudoku multijoueur en réseau développé en C sous Linux, dans le cadre du cours 
de Programmation Système & Réseau à l'ISI Kef.

## Fonctionnalités
- Serveur TCP multithread (POSIX threads), 2 joueurs max + file d'attente
- Client graphique GTK3 (grille 9x9 interactive) et client terminal
- 3 niveaux de difficulté, validation des coups en temps réel
